Model danych (SQLAlchemy)

3 TYPY UŻYTKOWNIKÓW
JOB_SEEKER – osoba szukająca pracy
dodawanie aplikacji
zarządzanie firmami
dodawanie rozmów
przeglądanie statystyk swoich
importować ogłoszenia
zarządzać swoim profilem

ADMIN – zarządza użytkownikami i systemem
przegląd wszystkich użytkowników
zmiana ról
usuwanie użytkowników
usuwanie ogłoszeń
przegląd globalnych statystyk
blokować konta

RECRUITER – osoba dodająca ogłoszenia
dodawać oferty
edytować oferty swoje
usuwać swoje oferty
przeglądać aplikacje do swoich ogłoszeń
zmieniać status kandydatów

ENUM:
JOB_SEEKER = "job_seeker"
RECRUITER = "recruiter"
ADMIN = "admin"
	

Tabela User
id PK
username TEXT, UNIQUE
email TEXT, UNIQUE
password_hash
role (ENUM: job_seeker / recruiter / admin) - domyślna job_seeker
created_at

RELACJE:
1 User może mieć wiele aplikacji
1 User może dodać wiele ogłoszeń - jeśli recruiter


JobOffer
id 
title
description
responsibilities
requirements
location - na razie String, docelowo id => przygotować bazę miast
salary_min
salary_max
type_of_contract (B2B, ZLECENIE, UMOWA O PRACĘ)
level (JUNIOR, MID, SENIOR)
job_type (ZDALNA/HYBRYDOWA/STACJONARNA)
is_active
created_at
expired_at

Do dodania później:
recruiter_id - Relacja z tabelą User ( 1 User może mieć wiele ogłoszen)





Company
id PK
user_id (FK -> User)
name
website
location
notes
created_at

RELACJE:
1 firma -> wiele aplikacji użytkowników, czyli dużo chętnych
1 firma -> wiele ogłoszeń

Application - Aplikacja użytkownika
id (PK)
user_id (FK → User)
company_id (FK → Company, nullable)
job_offer_id (FK → JobOffer, nullable)
position
status (ENUM)
applied_date
response_date
salary_min
salary_max
job_url
notes
created_at
updated_at

Relacje:

N → 1 User
N → 1 Company
N → 1 JobOffer
1 → N Interviews


Interview

id
application_id (FK)
scheduled_at
type (ENUM: hr, technical, final)
notes

Relacja:

N → 1 Application


User (1)
 ├── (N) Applications
 └── (N) JobOffers

Company (1)
 ├── (N) JobOffers
 └── (N) Applications

JobOffer (1)
 └── (N) Applications

Application (1)
 └── (N) Interviews
